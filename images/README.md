## Image Specifications

### Recommended Sizes:
- **Hero Images:** 1920x1080px (16:9 aspect ratio)
- **Feature Images:** 1200x800px (3:2 aspect ratio)  
- **Thumbnail Images:** 400x300px (4:3 aspect ratio)
- **Logo:** 300x100px (3:1 aspect ratio, transparent PNG)

### File Format Guidelines:
- **Photos:** JPEG format, optimized for web (under 500KB each)
- **Graphics/Logos:** PNG format with transparency
- **Quality:** 80-85% JPEG quality for optimal balance
- **Alt Text:** All images should have descriptive alt text for accessibility

## Optimization Notes

- All images should be compressed for web use
- Use WebP format when possible for better compression
- Implement lazy loading for non-critical images
- Include responsive image sizes for different screen resolutions
- Add appropriate alt text for SEO and accessibility
